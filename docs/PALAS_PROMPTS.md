# Prompts de imagen de las 30 palas

> Para generar una imagen por pala con IA, todas con el mismo estilo. Basado en [`PALAS.md`](PALAS.md).
> Cada prompt es **el bloque de estilo + la descripción de la pala**. No cambiéis el bloque de estilo entre palas: es lo que hace que las 30 salgan iguales.
> Los prompts van en inglés porque los generadores de imágenes los entienden mejor.

## Bloque de estilo (va delante de cada pala)

```
Game item icon for a Roblox digging game. A single shovel, full length, shown diagonally from the bottom-left (handle) to the top-right (blade), centered, filling about 80% of the square frame. Stylized 3D cartoon toy look built from chunky blocky pieces with Lego-like studs on the surfaces, soft rounded bevels, bright saturated colors, clean thick dark outline, soft studio lighting from the top-left, gentle drop shadow under the shovel. Plain background: smooth radial gradient matching the rarity color (light in the center, darker at the edges). No text, no letters, no logos, no hands, no people. Square 1:1.
```

**Color de fondo por rareza** (añadir al final del bloque: `Background color: …`):

| Rareza | Fondo |
|---|---|
| Común | light grey |
| Poco común | soft green |
| Raro | sky blue |
| Épico | purple |
| Legendario | golden orange |
| Mítico | crimson red |
| Cósmico | deep indigo with tiny stars |
| Secreto | black with a faint dark-red glow |
| Eterno | dark violet with pink energy wisps |
| Divino | white-gold with a soft rainbow halo |

**Más brillo cuanto más rara:** Común y Poco común sin efectos; desde Raro, `a few small sparkles`; desde Épico, `soft glow around the blade`; desde Mítico, `floating particles around the shovel`; desde Cósmico, `small objects orbiting the shovel`; Divino, `radiant light rays and a halo`.

## Cómo montar el prompt completo (ejemplo, pala 1)

```
Game item icon for a Roblox digging game. A single shovel, full length, shown diagonally from the bottom-left (handle) to the top-right (blade), centered, filling about 80% of the square frame. Stylized 3D cartoon toy look built from chunky blocky pieces with Lego-like studs on the surfaces, soft rounded bevels, bright saturated colors, clean thick dark outline, soft studio lighting from the top-left, gentle drop shadow under the shovel. Plain background: smooth radial gradient matching the rarity color (light in the center, darker at the edges). No text, no letters, no logos, no hands, no people. Square 1:1. Background color: light grey.
A beginner shovel: a crooked light-brown wooden stick as the handle, tied with beige rope to a flat grey stone blade, a small green fern curled around the handle. No effects.
```
